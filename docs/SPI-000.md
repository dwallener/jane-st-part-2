# SPI-000: First Canonical Protocol Frontend

**Status:** anonymous four-pin SPI inference implemented  
**Date:** 2026-09-30  
**Decision gate:** advance a known protocol beyond activity profiling without
supplying its label, roles, mode, or bit order

## Search space

The first SPI frontend accepts an anonymous four-pin waveform and an eight-bit
word bound. It enumerates:

```text
4! role assignments
× 2 select active levels
× 2 clock idle levels
× 2 sampling edges
× 2 bit orders
= 384 hypotheses
```

The two data pins are provisionally named `data_a` and `data_b`; request versus
response direction is not supplied.

Each surviving hypothesis must contain exactly one select interval, keep the
clock at its proposed idle level outside that interval, sample exactly eight
bits per data pin, and never change data on the proposed sampling edge.

## Canonical corpus result

All eight SPI cases pass:

- modes 0, 1, 2, and 3;
- MSB-first and LSB-first fixtures for each mode; and
- simultaneous words on both data lines.

For every case, the search uniquely recovers:

- the select pin and active-low polarity;
- the clock pin and idle level;
- leading versus trailing sampling edge; and
- the unordered pair of data pins.

Exactly four hypotheses survive from 384. They differ only by two symmetries
not observable from anonymous voltage levels in a single transfer:

1. swapping the names of the two data directions; and
2. consistently reversing bit order and the numeric word representation.

The learner retains all four instead of using the golden SPI label to select
one.

## Benchmark movement

The known-corpus matrix now reaches `spi_symbols` for all eight SPI cases.
UART and I²C remain at `activity_profile` with their prior unsupported reasons.
This is the first canonical protocol family to advance through autonomous pin
roles, physical timing, and symbol extraction.

## Non-claims

- The waveform has exactly four relevant pins.
- Word width is supplied as eight bits.
- There is one selected transfer with no inter-word gaps.
- Electrical direction is not observed, so MOSI versus MISO remains unnamed.
- Multiword transfers, three-wire SPI, daisy chains, and independent output
  timing are absent.
- No behavioral request/response model is learned from a single exchange.
