# SPI-001: Behavior Resolves Physical Direction

**Status:** multi-transfer SPI learning and compilation implemented  
**Date:** 2026-09-30  
**Decision gate:** use corpus-wide causal regularity to remove a physical-role
ambiguity, then generalize and compile the result

## Question

`SPI-000` recovers clock, select, timing, and the two data pins from one
anonymous waveform, but it cannot name the data directions. Voltage levels
alone do not reveal which endpoint drove a pin.

Can repeated behavior break that symmetry without using scorer-only labels?

## Corpus

Eight transfers share one unknown SPI configuration. Requests span `0xA0`
through `0xAF` with enough variation to exercise every low request bit. The
synthetic peripheral deliberately returns a lossy response:

```text
response = 0x60 | request[1:0]
```

Several requests therefore produce the same response. The held-out request is
`0xA7`, whose response must be `0x63`.

## Joint inference

Each waveform independently begins with the 384 physical hypotheses from
`SPI-000`. Only hypotheses shared by every waveform proceed to behavioral
learning. For each remaining data-line orientation, the existing mask/template
learner asks whether one line is a deterministic generalized function of the
other across the entire corpus.

The correct orientation is complete. The reverse orientation is not a
function: identical response words correspond to multiple original requests,
so at least one output bit has no consistent expression.

## Result

For every SPI mode and fixture bit order:

- request direction resolves uniquely to MOSI's anonymous pin index;
- response direction resolves uniquely to MISO's anonymous pin index;
- the two bit-order representations remain equivalent;
- each surviving behavioral model compiles to one 10-byte transition; and
- the compiled program answers unseen `0xA7` with `0x63`.

Exact replay cannot answer `0xA7`.

## Causal asymmetry control

A second corpus uses the reversible relation:

```text
response = 0x60 | request[3:0]
```

Both directions are then expressible by the template language, so all four
direction/order candidates remain. This demonstrates that direction was not
deduced from a hidden MOSI label or arbitrary preference; it became observable
only because the lossy behavior supplied causal asymmetry.

## Architectural consequence

Physical and behavioral inference should not be isolated stages with a hard
one-way boundary. A small set of physical candidates can flow upward into the
behavior learner, and behavioral consistency can prune physical uncertainty.
The resulting hierarchy is a constraint system, not merely a decoder pipeline.

## Non-claims

- Transfers remain one byte with a supplied corpus grouping.
- The response begins simultaneously with the request.
- The behavior fits the existing constant/copy/invert template language.
- Bit order remains representationally ambiguous.
- Active probing and electrical drive direction are not used.

serialized hierarchical model. It stores one canonical 10-byte program, a
